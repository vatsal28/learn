# Learn

A daily two-lesson journal: one system-design lesson, one agents/AI lesson,
published automatically each day.

Each edition is short — two compact ideas, a diagram, and a takeaway — with
a longer "2-minute version" available behind a toggle if you want more depth.

Read it at **[vatsal28.github.io/learn](https://vatsal28.github.io/learn/)**.

## Archive

Every edition is browsable at [`/archive/`](https://vatsal28.github.io/learn/archive/),
newest first, with permalinks like `/2026/07/24/`.

## Data

Each edition's sanitized lesson content is also available as JSON under
[`/data/`](https://vatsal28.github.io/learn/data/), one file per date
(`YYYY-MM-DD.json`), for anyone who wants to read or reuse it programmatically.

## What this is

This site is generated and published automatically from a private pipeline.
This repository holds only the published artifacts: the static site and the
sanitized edition data. There's no build step here — the HTML and JSON in
this repo are exactly what's served.
